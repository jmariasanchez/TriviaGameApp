# A two-player round

[Watch the full recording (MP4, 1:30)](walkthrough.mp4) · [Back to the game](../../README.md)

Emi and Kai play two questions each on the same iPad. Jump to **0:28** for player setup, **0:33** for the first live question, or **1:20** for the final scores. The recording keeps the countdown in real time.

| Stage | Screenshots | What to look for |
| --- | --- | --- |
| Start | [iPad home](01-home.webp) · [Mac Catalyst home](mac-home.webp) | The bilingual menu in Light mode on both platforms. |
| Configure | [Settings](02-settings.webp) · [Saved](03-saved.webp) | Two questions per player, with no category, type or difficulty restrictions. |
| Add players | [Missing names](04-validation.webp) · [Ready to play](05-players.webp) | The game asks for both names before starting. |
| Play | [First question](06-question.webp) · [Correct](07-correct.webp) · [Incorrect](08-incorrect.webp) | Emi earns one point. The next question waits until the feedback is dismissed. |
| Pass the iPad | [Second player's turn](09-next-player.webp) · [Time expired](10-timeout.webp) | Kai gets a fresh countdown, runs out of time, then skips the last question. |
| Finish | [Final scores](11-final.webp) · [Loading results](12-loading.webp) · [Leaderboard](13-leaderboard.webp) | The final tally is Emi 1, Kai 0. Both results are saved on the device. |
| Search | [Filtered leaderboard](14-search.webp) | Searching for Emi narrows the table to one result. |
